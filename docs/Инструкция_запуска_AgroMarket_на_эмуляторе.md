# AgroMarket — инструкция по запуску на компьютере

**Для кого:** заказчик или тестировщик без настроенной Android-среды.  
**Операционная система:** Windows 10/11, 64-bit.  
**Файл приложения:** `AgroMarket-demo-1.0.0.apk`.  
**Версия приложения:** 1.0.0, package `ru.agromarket`.  
**Дата инструкции:** 22 июня 2026 года.

> Для просмотра приложения не нужно открывать исходный код. Достаточно один раз установить Android Studio и виртуальный телефон, затем перетащить APK на экран эмулятора.

## Быстрый способ — одной командой

В комплект входит `START_AGROMARKET.bat`. Это основной вариант для заказчика:

1. Полностью распакуйте ZIP-архив в обычную папку.
2. Дважды нажмите `START_AGROMARKET.bat`.
3. В запросе контроля учетных записей Windows нажмите «Да».
4. Дождитесь автоматической установки компонентов и запуска AgroMarket.

BAT самостоятельно:

- проверяет 64-битную Windows и аппаратную виртуализацию;
- включает Windows Hypervisor Platform;
- при необходимости устанавливает Microsoft OpenJDK 17 через `winget`;
- скачивает официальные Android SDK Command-line Tools;
- устанавливает Android Emulator, Platform Tools и Android 14 / API 34;
- создает виртуальный Pixel;
- запускает Android;
- устанавливает `AgroMarket-demo-1.0.0.apk`;
- открывает приложение.

В комплект V4 уже включен официальный архив Android Command-line Tools. Повторно скачивать первые 143 МБ не требуется; установщик распаковывает их системным `tar.exe`, а не нестабильным `Expand-Archive` из Windows PowerShell 5.1.

При первом запуске потребуется стабильный интернет, до 16 ГБ свободного места и обычно 10–40 минут на загрузку компонентов. Последующие запуски выполняются значительно быстрее.

Если Windows Hypervisor Platform была отключена, BAT предложит перезагрузить компьютер и зарегистрирует автоматическое продолжение установки после входа в Windows.

Если установка остановится, окно теперь останется открытым, а рядом с BAT появится `AgroMarket_setup.log`. Этот файл нужно отправить разработчику: в нем указаны конкретный этап, текст ошибки и номер строки. Сам по себе «Код ошибки 1» причину не определяет.

> BAT не может включить Intel VT-x или AMD-V внутри BIOS/UEFI. Если аппаратная виртуализация отключена, скрипт остановится и покажет, что именно нужно включить. Ручная инструкция ниже остается запасным вариантом.

## 1. Что нужно получить от разработчика

Заказчику передаются только два файла:

1. `AgroMarket-demo-1.0.0.apk` — приложение для виртуального Android-телефона.
2. `Инструкция_запуска_AgroMarket_на_эмуляторе.pdf` — эта инструкция.

Для полной проверки модерации дополнительно нужны:

- адрес админки: `https://agro.assaru.space/admin/`;
- логин и пароль администратора, переданные отдельно безопасным способом;
- обычный пользовательский аккаунт или реальный email для регистрации;
- 2–5 тестовых фотографий товара.

Не нужно передавать исходники, `.env`, Firebase service account, ключи API или другие серверные файлы.

## 2. Требования к компьютеру

Официальные минимальные требования Google для Android Studio с эмулятором на Windows:

| Компонент | Минимум | Рекомендуется для комфортной работы |
|---|---|---|
| Windows | Windows 10, 64-bit | Актуальная Windows 11, 64-bit |
| Оперативная память | 16 ГБ для Studio + Emulator | 32 ГБ |
| Свободное место | 16 ГБ | SSD, не менее 32 ГБ свободно |
| Процессор | Intel VT-x или AMD-V, включено в BIOS/UEFI | Современный Intel Core или AMD Ryzen |
| Экран | 1280×800 | 1920×1080 |

Компьютеры Windows на ARM-процессорах официально не поддерживаются Android Studio. Если компьютер слабый, имеет 8 ГБ памяти или не поддерживает виртуализацию, проще установить APK на реальный Android-телефон.

## 3. Проверка виртуализации

### 3.1. Быстрая проверка в Windows

1. Нажмите `Ctrl + Shift + Esc`.
2. Откройте «Производительность» → «ЦП».
3. Найдите строку «Виртуализация».
4. Нормальный результат: «Включено».

Если указано «Отключено», войдите в BIOS/UEFI и включите:

- Intel: `Intel Virtualization Technology`, `VT-x`;
- AMD: `SVM Mode`, `AMD-V`.

Название и клавиша входа зависят от производителя компьютера. Обычно при включении используются `F2`, `Del`, `F10` или `Esc`.

### 3.2. Windows Hypervisor Platform

Google рекомендует на Windows использовать Windows Hypervisor Platform.

1. Откройте поиск Windows.
2. Введите «Включение или отключение компонентов Windows».
3. Установите флажок **Windows Hypervisor Platform**.
4. Нажмите OK.
5. Перезагрузите компьютер.

Если пункт недоступен, сначала включите виртуализацию в BIOS/UEFI и установите обновления Windows.

## 4. Установка Android Studio

1. Откройте официальный сайт: `https://developer.android.com/studio`.
2. Нажмите **Download Android Studio**.
3. Скачайте установщик `.exe` для Windows.
4. Запустите установщик.
5. Оставьте выбранными компоненты **Android Studio** и **Android Virtual Device**.
6. Завершите установку и запустите Android Studio.
7. В первом мастере выберите стандартную установку — **Standard**.
8. Подтвердите лицензии и дождитесь загрузки Android SDK, Platform Tools и Emulator.

Загрузка может занять 10–30 минут. Потребуется стабильный интернет и несколько гигабайт свободного места.

## 5. Создание виртуального Android-телефона

### 5.1. Открыть Device Manager

На стартовом экране Android Studio нажмите:

**More Actions → Virtual Device Manager**.

Если открыт какой-либо проект:

**Tools → Device Manager**.

### 5.2. Создать устройство

1. Нажмите **Create Device** или значок `+`.
2. Выберите категорию **Phone**.
3. Выберите **Pixel 7**, **Pixel 6** или **Medium Phone**.
4. Нажмите **Next**.
5. Выберите образ **Android 14 / API 34** с пометкой **Google APIs** или **Google Play**.
6. Если рядом есть кнопка Download, скачайте образ и примите лицензию.
7. После загрузки выберите образ и нажмите **Next**.
8. Оставьте настройки по умолчанию:
   - ориентация Portrait;
   - Graphics — Automatic или Hardware;
   - память — стандартное значение.
9. Нажмите **Finish**.

Приложение поддерживает Android 8.0 и новее (`minSdk 26`), но для демонстрации рекомендуется Android 14 / API 34.

## 6. Запуск эмулятора

1. В Device Manager найдите созданный виртуальный телефон.
2. Нажмите кнопку запуска ▶ в строке устройства.
3. Дождитесь появления рабочего стола Android.
4. Первый запуск может занимать 2–5 минут.
5. Убедитесь, что внутри эмулятора открываются сайты или работает поиск — приложению нужен интернет.

Не закрывайте окно виртуального телефона во время установки APK.

## 7. Установка AgroMarket

### Основной способ — перетаскивание APK

1. Откройте в Проводнике папку с `AgroMarket-demo-1.0.0.apk`.
2. Зажмите файл левой кнопкой мыши.
3. Перетащите его прямо на экран запущенного виртуального телефона.
4. Отпустите файл.
5. Дождитесь сообщения об успешной установке.
6. Откройте список приложений свайпом снизу вверх.
7. Найдите **AgroMarket** и нажмите на иконку.

Это официальный способ установки отдельного APK в Android Emulator.

### Запасной способ через ADB

Если перетаскивание не работает:

1. Убедитесь, что эмулятор запущен.
2. Откройте PowerShell.
3. Выполните команду, подставив реальный путь к APK:

`& "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe" install -r "C:\Путь\AgroMarket-demo-1.0.0.apk"`

Успешный результат: `Success`.

## 8. Первый вход

### Вариант 1 — готовый пользователь

1. Запустите AgroMarket.
2. Введите выданные email и пароль.
3. Нажмите «Войти».

### Вариант 2 — новая регистрация

1. Нажмите «Регистрация».
2. Укажите реальный email.
3. Получите код из письма; проверьте папку «Спам».
4. Введите шестизначный код.
5. Установите пароль не короче 8 символов.
6. После регистрации приложение откроет каталог.

На Android 13/14 приложение может запросить разрешение на уведомления. Нажмите «Разрешить», чтобы увидеть push об изменении статуса объявления.

## 9. Как показать заказчику пользовательскую часть

### 9.1. Каталог

Проверьте:

- загрузку карточек;
- чипы «Все», «Продажа», «Агроуслуги», «Земли»;
- строку поиска;
- быстрые группы категорий;
- прокрутку и автоматическую загрузку следующей страницы;
- добавление объявления в избранное.

### 9.2. Карточка объявления

Откройте любое объявление и покажите:

- перелистывание фотографий;
- полноэкранную галерею;
- увеличение изображения;
- цену, регион, категорию и описание;
- кнопку «Позвонить»;
- кнопку «Контакты»;
- добавление в избранное.

В эмуляторе кнопка «Позвонить» откроет номеронабиратель, но реальный звонок не выполняется.

### 9.3. Избранное

1. Откройте вкладку «Избранное».
2. Проверьте сохраненное объявление.
3. Удалите его свайпом.
4. Нажмите «Отменить» в нижнем уведомлении.

### 9.4. Профиль

Нажмите иконку профиля в каталоге. Покажите:

- изменение имени, фамилии и телефона;
- загрузку аватара;
- смену пароля;
- список «Мои объявления»;
- статусы объявлений;
- выход из аккаунта.

## 10. Как загрузить тестовые фотографии в эмулятор

Перед созданием объявления подготовьте на ПК 2–5 обычных файлов JPG или PNG без персональных данных.

1. Запустите виртуальный телефон.
2. Перетащите фотографии с ПК на экран эмулятора.
3. Android сохранит их в папку `/sdcard/Download/`.
4. В AgroMarket откройте «Разместить».
5. На шаге фотографий нажмите «Добавить».
6. В системном выборе файлов откройте «Downloads» или «Недавние».
7. Выберите минимум 2, максимум 5 фото.

## 11. Полный сценарий объявления и модерации

Чтобы заказчик увидел весь цикл, одновременно используйте Android Emulator и админку в браузере.

### Шаг A — пользователь создает объявление

1. В Android нажмите «Разместить».
2. Выберите «Продать», «Агроуслуги» или «Земли СХ назначения».
3. Выберите категорию и подкатегорию.
4. Заполните название, описание, цену и телефон.
5. Выберите субъект РФ; район и населенный пункт необязательны.
6. Добавьте 2–5 фото.
7. Нажмите «Отправить на модерацию».

### Шаг B — администратор возвращает на исправление

1. На ПК откройте `https://agro.assaru.space/admin/`.
2. Войдите под администратором.
3. Откройте «Модерация».
4. Найдите созданное объявление.
5. Нажмите «На исправление».
6. Напишите комментарий и при необходимости добавьте фото-пример.
7. Подтвердите действие.

### Шаг C — пользователь исправляет

1. Вернитесь в Android.
2. Откройте профиль → «Мои объявления».
3. Если статус не обновился, выйдите из профиля и откройте его заново либо перезапустите приложение.
4. Откройте объявление со статусом «На доработке».
5. Проверьте комментарий и фото модератора.
6. Нажмите «Исправить и отправить снова».
7. Измените данные и повторно отправьте объявление.

### Шаг D — администратор публикует

1. Обновите раздел «Модерация» в админке.
2. Откройте повторно отправленное объявление.
3. Нажмите «Опубликовать».
4. В Android снова откройте «Мои объявления».
5. Убедитесь, что статус стал «Активно».
6. Найдите объявление в каталоге.

### Шаг E — запрос контактов

1. Под другим пользовательским аккаунтом откройте объявление.
2. Нажмите «Контакты».
3. В админке откройте «Заявки на контакты».
4. Проверьте варианты «Одобрить бесплатно», «Назначить цену» и «Отклонить».

## 12. Что заказчик не увидит в текущей версии

Это не ошибка эмулятора:

- в каталоге Android пока нет фильтра по субъекту РФ и диапазону цены;
- оплата размещения, продвижения и контактов в Android не подключена;
- отдельного экрана «Мои запросы на контакты» нет;
- видимый фильтр статуса в таблице «Все объявления» админки сейчас не передает статус в API;
- эмулятор не выполняет реальные телефонные звонки.

## 13. Решение типовых проблем

### Эмулятор не запускается или работает очень медленно

- проверьте «Диспетчер задач → Производительность → ЦП → Виртуализация: включено»;
- включите Windows Hypervisor Platform и перезагрузите ПК;
- закройте тяжелые программы и другие виртуальные машины;
- в Device Manager откройте меню устройства → **Cold Boot Now**;
- если не помогло — **Wipe Data** и повторный запуск.

### Черный экран или графические артефакты

Откройте редактирование виртуального устройства → Show Advanced Settings → Graphics. Выберите **Automatic**, а если проблема осталась — **Software**.

### APK не устанавливается

- убедитесь, что перетаскиваете именно `AgroMarket-demo-1.0.0.apk`;
- дождитесь полной загрузки Android;
- удалите старую AgroMarket с эмулятора и повторите установку;
- используйте запасную ADB-команду;
- при конфликте выполните `adb uninstall ru.agromarket`, затем установите APK заново.

### «Ошибка сервера» или каталог не загружается

- проверьте интернет внутри эмулятора;
- откройте на ПК `https://agro.assaru.space/docs`;
- отключите VPN/прокси, если он блокирует домен;
- перезапустите приложение;
- если сайт API недоступен, проблема находится на сервере, а не в эмуляторе.

### Не приходит код регистрации

- используйте реальный email;
- проверьте «Спам» и «Промоакции»;
- подождите 1–2 минуты;
- повторный запрос делайте после ожидания, не нажимайте кнопку много раз подряд.

### Фото не видны в выборе файлов

- перетащите JPG/PNG на экран уже запущенного эмулятора;
- откройте приложение «Files» и проверьте папку Downloads;
- затем повторно откройте выбор фото в AgroMarket.
